System architecture

Unity VR Client

  • Records required session events
  • Task and procedural outcomes
  • Safety and waste indicators

AWS Backend

  • Cognito: identity and roles
  • API Gateway: HTTPS endpoints
  • Lambda: validation and logic
  • DynamoDB: structured records
  • CloudWatch: logs and metrics
→

Node.js Dashboard

  • Authenticated read requests
  • Class and learner summaries
  • Live session event views
  • Criterion and progress reports
  • No remote headset control
This delivery intentionally implements only the static dashboard. CloudDataService is the replacement seam for the future AWS API client; the UI pages do not depend directly on mock data.
